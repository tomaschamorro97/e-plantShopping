# e-plantShopping

This website is built for the purpose of implementing the skills and knowledge acquired during the IBM Course "Developing Front-End Apps with React" as part of the IBM Full Stack specialization course. The website  consists of an interface that allows you to browse several houseplants and add them to a shopping cart. The shopping cart contains regular functionality of eCommerce applications.

Furthermore, the website contains a landing page where the customers can get an overview about the application itself and the purpose of the company. In order to get started, user must click on "Get Started" to take a peak into the available houseplants on the website. For this objective, a product listing page with all the available items should be displayed and should have the functionality to add them to the shopping cart. Once the customer has selected the desired houseplants, he/she can proceed to the shopping cart page, where all the details about the order, e.g. price, quantity, are displayed. The website is stored in a public GitHub repository. 

This application is built using React.
